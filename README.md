# 设备工具箱 · 离线版

离线可用的设备工具集合，纯静态 HTML，无需联网、双击即用，手机电脑通用。

## 板块

- `index.html` — 首页 / 导航
- `1.设备报表生成器.html` — 设备报表生成
- `2.Excel表格双向对比工具.html` — 两个 Excel 表格双向差异对比
- `3.离线对比出维修表.html` — 离线对比并生成维修表
- `4.全流程串联.html` — 全流程串联

## 使用

直接用浏览器打开 `index.html` 即可。所有数据处理均在本地完成，数据不离开本机。
